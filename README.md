# لوحة إدارة التسوق الحر

لوحة ويب لإدارة الطلبات.

## قبل التشغيل
1. أنشئ مشروع Firebase.
2. فعّل Authentication > Email/Password.
3. أنشئ حساب المدير من Firebase Authentication.
4. ضع إعدادات Web App داخل `app.js`.
5. استضافة اللوحة يمكن أن تكون Firebase Hosting أو أي استضافة HTTPS.

## مهم للأمان
لا تعتمد على إخفاء رابط اللوحة. يجب تقييد Firestore بحيث لا يستطيع تعديل الطلبات إلا حسابات الإدارة/السائقين المصرح لهم، ويفضل استخدام Custom Claims مثل `admin: true`.

## الوظائف الحالية
- تسجيل دخول المدير.
- إحصائيات الطلبات.
- قائمة الطلبات.
- تفاصيل الطلب.
- تعديل سعر البضاعة.
- تعديل أجرة التوصيل.
- حساب المجموع.
- تغيير حالة الطلب.
- قائمة الزبائن.
